电芯型号不是容量结论；替代同尺寸电芯也要评估性能、热、安全与认证。现在把这些输入接到电路上。

1先把 PRD 翻译成“电气输入”

PRD 语言工程问题会影响什么
“支持 65W 快充”输入/输出分别多少？哪些电压档？可持续多久？拓扑、IC、MOSFET、电感、PCB、热
“双口同时快充”总功率还是每口功率？插拔时如何重分配？端口策略、固件、器件裕量、测试组合
“无线充”Qi 版本、功率、线圈位置、异物检测、兼容机型？线圈、磁材、结构间距、热、认证
“10000mAh”电芯口径还是额定输出容量？串并联怎样组织？电芯数量、能量、壳体、标识与测试
协议不是量产末期刷个软件就能补的功能。它会提前进入 IC 选型、端口定义、器件耐压电流、热设计和测试矩阵。

21S2P 与 2S：没有免费的架构

1S2P：一串两并

电压较低、容量叠加。高功率时电池侧电流可能更大，对铜损、MOSFET 与连接路径提出要求；并联前要控制电芯一致性。

2S：两串

电池包电压更高，同功率下电流可降低；但要处理串联均衡、更高耐压与充放电拓扑复杂度。

别把“并联更便宜、串联更高级”当结论。最终成本取决于 IC 方案、器件额定、PCB、散热、认证、产量与供应成熟度。

3PCBA 上这几类器件在干什么

协议 / 电源 IC

识别握手、控制升降压和端口策略。要锁型号、版本与协议覆盖。

MOSFET + 电感

承担开关与储能转换。导通电阻、开关损耗、饱和电流和温升都重要。

PCB + NTC

铜箔承载电流并扩散热量；NTC 提供局部温度信息，位置决定“看见哪里”。

● 走访观察 组装厂把 PCBA 贴片和部分方案开发交由外部伙伴。产品团队仍要控制完整 BOM、替代料、固件版本、测试程序与异常责任。

4PD、MFi、Qi：三个不同问题

名词它主要回答常见误解
USB PD 等快充协议有线端口如何协商电压、电流与功率“标了快充，就支持所有品牌所有档位”
Apple MFi使用指定 Apple 授权技术/部件的配件项目“所有 USB-C 充电宝都必须 MFi”或“MFi 是通用品质天花板”
Qi 认证无线充电的标准一致性、安全相关要求与互操作“能无线充就等于已认证、兼容所有设备”
✓ 核验原则 Apple 官方 FAQ 明确：不使用 MFi 授权技术的 USB-C 充电配件不需要加入 MFi；Qi 则由 WPC 体系管理。两者不能互相替代。

5测试不是一个按钮，是组合矩阵

最少要考虑：每个输入档、每个输出档、单口/多口、低/中/高电量、冷启动/热态、线材与负载、插拔重分配、保护触发与恢复。无线充还要覆盖对位偏差、异物、壳体间距、代表性机型与温升。

● 走访观察

产线使用真实手机做最终兼容性抽查很有价值，但它不能取代仪器化电气测试和认证矩阵；真实设备更适合捕捉“用户会遇到但台架未必复现”的互操作问题。

6本课测验

1. “65W”在 PRD 中最需要补充什么？

正确。峰值标签不能代替持续能力定义。

功率承诺必须可复现、可验收。

2. 2S 相比 1S2P 的典型变化是？

正确，要看整个系统权衡。

架构没有脱离方案和产量的固定成本结论。

3. 普通 USB-C 充电宝是否一律需要 MFi？

正确。认证边界要看实际技术与产品形态。

MFi 不是所有 USB-C 产品的通用门槛。

4. 真实手机测试可以取代台架测试吗？

正确。仪器测试可控，真实设备补充互操作。

单一真实设备无法覆盖电气边界。
