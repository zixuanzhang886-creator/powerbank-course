1PC 与 PC/ABS：先锁“牌号”，再谈材料名

维度PCPC/ABS
直觉韧性、耐热、透明牌号选择较多兼顾 PC 与 ABS 的部分性能，加工与外观选择丰富
真实选型看精确牌号的冲击、热、流动、耐化学、颜色、阻燃、环保与加工数据
阻燃两类都不能仅凭材料名宣称阻燃；需看具体 FR 牌号、UL 94 等级及对应试样厚度
“PC/ABS 天然阻燃”是错误的简化。同一材料家族内有非阻燃与不同阻燃等级的牌号。认证和规格必须精确到制造商 + 商标 + 牌号 + 颜色/厚度等适用条件。

2颜色不是“加点色粉”这么简单

色粉现场混配

灵活、门槛低，但分散、计量、粉尘、批差和换色清机更难控制。

色母粒

颜料预分散在载体中，计量与清洁更友好；要验证载体相容和添加比例。

预配色 / 抽粒

材料商先复合造粒，一致性潜力较好；会增加 MOQ、交期、库存与变更管理。

颜色验收应定义光源、观察角度、表面纹理、样件厚度与组装状态。ΔE 是量化工具，限度样是现实边界，两者都不能脱离测量条件。

● 走访观察

现场把“同色不同材、不同工艺后颜色偏差”作为常见沟通点。产品经理不要只拿一块色板签样，应至少看最终材料、纹理、后加工和组装间隙下的整机。

4“电镀不会刮花”为什么不成立

镀层或涂层都有具体层系、厚度、附着和耐磨边界。划伤、针孔、脱层、橘皮、色差等风险取决于底材、前处理、工艺和使用环境。所谓“看起来像金属”不等于拥有金属的全部耐久性。

● 走访观察 走访记录里出现了喷涂约 0.8 元、某类镀层约 1.6 元的口头价格。这里只能作为当时特定供应商、尺寸、颜色、数量和良率条件下的项目观察，不能用作行业报价基准。
报价要拆成：前处理 + 主工艺 + 遮蔽/治具 + 检验 + 良率损耗 + 包装保护 + 物流 + 环保与外协管理。

5CMF 签样应该签什么

材料样精确树脂牌号、颜色与厚度
工艺样纹理、膜层、印刷参数
整机样相邻件色差、缝隙与光泽
限度样可接受最差边界
可靠性样磨损、汗液/化学品、温湿等

? 项目待确认 具体可靠性项目与条件要来自目标市场、使用场景、企业规范和材料/涂层系统，不能照抄另一项目。

6本课测验

1. “PC/ABS”本身能否证明达到阻燃等级？

正确。材料家族名不能代替等级证据。

同一材料家族有不同牌号。

2. 预配色的典型代价是？

正确。一致性提升不等于零风险。

任何配色路线仍需批次控制。

3. 电镀塑胶件是否绝不会刮花或剥落？

正确。任何表面系统都有使用边界。

金属视觉不等于无限耐久。

4. 最有意义的颜色签样状态是？

正确。颜色是材料、表面与观察条件的结果。

屏幕不能代替实物工艺样。
