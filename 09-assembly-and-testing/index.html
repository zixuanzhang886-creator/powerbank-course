3焊接：控制的是能量，不是“设备名光环”

维度激光焊电阻焊 / 点焊
能量方式聚焦光能局部熔合电流通过接触电阻产生热并加压
优势方向局部、精细、轨迹灵活，能量与几何可控潜力高成熟、节拍快、成本路径清晰
关键控制焦点、功率/波形、速度、间隙、表面、烟尘与飞溅电极状态、压力、电流、时间、表面与压痕
验证外观只是第一层；还需拉力/剥离、截面或等效强度、接触电阻、热影响与过程监控
激光焊并非“没有飞溅、没有热影响”。它通常能更集中地控制热输入，但参数、间隙和污染不当仍会带来飞溅、孔洞、裂纹或热损伤。

4螺钉、辅料与防漏装

扭矩 + 角度/圈数

只记峰值扭矩可能掩盖滑牙、浮锁或提前触底；结合角度、时间曲线和结果码能增强判定。

视觉 / 传感防呆

检查泡棉、绝缘片、NTC、石墨片、胶带与螺钉是否存在、位置是否正确。

称重

成本低、速度快，能发现部分漏件/错件，但不能证明位置、连接和功能正确。

返修控制

拆装、补焊、重复点胶都会改变可靠性；要定义次数、路径、复验和报废边界。

● 走访观察 现场使用锁螺钉轨迹、半成品测试、真机验证和称重等多层拦截。好产线不是“测试多”，而是每层测试覆盖清楚、互不假装替代。

5功能测试、老化、真机测试各自做什么

功能 / 电气测试

可控地测输入输出、协议、保护、功耗和关键电气边界。

老化

在规定充放电循环/时间与环境下暴露部分早期失效，并留下过程数据。

真机互操作

验证真实用户链路，捕捉协商、插拔、线材或机型组合问题。

三者是互补，不是三选一。老化也不是“做过就一定可靠”，要看条件、负载、覆盖、判定、设备校准和数据利用。

6良率先看 FPY

最终良率高，不代表过程健康。某批产品如果经过多次返修才过终检，出货数字看起来漂亮，隐含风险却更高。一次通过率 FPY（First Pass Yield）更能暴露工位稳定性；同时要看直通率、返修率、报废率和缺陷 Pareto。

工位 FPY = 第一次测试通过数 ÷ 进入该工位总数
整线直通率 ≈ 各关键工位 FPY 的连乘（简化理解）

7本课测验

1. 称重检查能证明什么？

正确，它是廉价防呆，不是万能测试。

重量相同也可能接错或位置错。

2. 激光焊是否天然没有飞溅和热影响？

正确。设备类型不能替代工艺窗口。

激光集中不等于零缺陷。

3. 老化可以取代功能测试和真机测试吗？

正确。覆盖不同层级。

老化不能完整测协议与互操作。

4. 为什么 FPY 比“返修后最终通过率”更敏感？

正确。返修会掩盖原始波动。

FPY 关注首次通过。

练课后练习

删掉一个工位

任选“称重、老化、真机测试”，假设因产能压力删除，写出漏失风险与替代控制。

替代控制必须说明覆盖率、检测率、误判与追溯，不能只写“加强巡检”。

做一张控制计划

为 NTC 粘贴写 CTQ、方法、频率、治具、判定、异常反应和记录字段。

位置正确还不够：还要控制胶量、贴合、线束应力与返修。
