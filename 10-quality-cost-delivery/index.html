030 秒复习

组装线的每个工位都应该有明确拦截对象、方法、判定、记录和异常反应。最后一课把这些证据连到质量、成本和交付。

1为什么注塑重“首件 + 巡检”，组装又常做 100%

注塑参数漂移、模具损伤等往往会连续影响一段产品，首件和过程巡检能较早发现系统性偏移；组装中的漏装、连接、功能等可能随机发生，关键工位常需要逐件防错或测试。最终抽样再验证整批/系统表现。

层级回答的问题典型方法
IQC 来料检验进厂的料对不对、能不能用？身份/批次、外观、尺寸、电性能、文件
首件 / IPQC 过程检验过程是否在正确窗口内稳定运行？首件批准、巡检、参数/治具监控、SPC
100% 在线检测关键随机失效是否被逐件拦截？防呆、视觉、扭矩、电气、条码关联
OQC / 抽样出货批是否满足整体判定？按抽样方案做外观、功能、包装与文件确认
抽样不能自动代替 100% 检测，100% 检测也不等于零漏检。要看失效严重度、发生率、检测能力、误判与破坏性测试成本。

2量具要匹配公差和特征

卡尺 / 千分尺

快速测常规外尺寸/厚度，但操作者、测力和接触位置会影响结果。

高度规 / 专用检具

在基准平台上测高度位置，或快速判定功能尺寸；检具也要校准、寿命和防错。

影像测量

适合二维轮廓、孔距与非接触边缘，但算法、光照和取边规则要锁定。

CMM 三坐标

适合复杂三维几何与基准体系；测针、装夹、程序与环境决定测量能力。

✓ 核验原则 计量溯源不等于“贴了校准标签”。结果要通过有记录的、不间断校准链连接到参考，并说明测量不确定度与适用范围。

3签样、限度样与抽样

签样件代表被批准的目标状态；限度样明确最差可接受边界，尤其适合难以完全数字化的外观缺陷。两者都要有编号、版本、批准人、有效期、保存条件和替换规则。

ISO 2859-1 等计数抽样标准用于按批检验的抽样方案。AQL 是抽样体系中的参数，不等于“允许生产这么多坏品”，也不适合拿来掩盖安全关键特性的逐件控制。

● 走访观察 工厂使用首件、巡检、签样、终检与 MES/条码等多层控制。审厂时应随机抽一个序列号反查原料批次、工位结果、返修与测试，而不是只看演示看板。

4MES 的价值是“把事实串起来”

唯一身份产品/批次/工单编码
投入物料电芯、PCBA、外壳等批次
过程结果设备、程序、参数、人员
测试返修原始值、判定、重测与处置
出货去向箱码、订单、客户与召回范围
激光装饰 ≠ 激光追溯。Logo/图案是外观工艺；唯一序列号只有和数据库中的物料、过程、测试、返修、出货关系连起来，才形成追溯。

● 走访观察 组装厂给出“工位约每秒 0.01 元”的口头估算，可用于快速敏感性思考，不能当正式行业费率。工资、自动化、稼动、管理分摊、地区和订单规模都会改变结果。

6交期从“冻结”才真正开始

真实上市周期 ≈ 需求冻结延误 + DFM/开模 + T0 + 多轮修模/签样
＋ 材料与外协准备 + 认证 + 小批验证 + 爬坡 + 物流

● 走访观察 模具供应商给出约 25 天到 T0 的项目口径。它取决于设计冻结、模具复杂度、钢料/标准件、排产和加工资源，只能作为特定场景估算。

“25 天 T0”不是“25 天量产”。T0 是第一次试模节点，后面可能还有尺寸、外观、结构、可靠性、纹理和量产窗口修正。

2. 回料规则如何记录？

4. 关键参数谁能改？
5. 治具寿命和校准如何管？

质量与追溯

10. 外协清单和审核？
11. 替代料/参数/场地变更如何批准？
12. 参观隔离、客户资料与 NDA 如何执行？

8毕业测验

1. 100% 在线测试是否意味着零漏检？

正确。测试系统本身也会误判和漏判。

“测了每一件”和“检出所有缺陷”不是一回事。

2. AQL 最准确的理解是？

正确。抽样判批不等于过程目标。

AQL 不能替代过程改善和关键特性控制。

3. MES 追溯最有说服力的审厂动作是？

正确。用真实记录验证闭环。

看板展示不等于数据完整。

4. 供应商承诺“25 天 T0”，产品经理应如何使用？

正确。T0 是节点，不是终点。

第一次试模后通常还有验证与迭代。

练毕业实战

做一页量产 Readiness Review

用 Q/C/D 三栏列出：CTQ 与证据、成本假设与敏感项、冻结/T0/认证/爬坡节点和 Top 5 风险。

每个风险都写 owner、截止日期、关闭证据；“持续跟进”不算行动。

做一次虚拟审厂

从本课 12 问中挑 6 问，写出“可接受证据”和“危险回答”。

危险回答通常是绝对化且无记录：一直这样做、从没出过问题、客户都认可。

把一个卖点追到出货

选“65W 双口快充”或“耐刮金属质感”，画出从 PRD 到架构、材料、工艺、测试、追溯的完整证据链。

如果链条中出现“供应商保证”，继续追问可量化条件和记录。
